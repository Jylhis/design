Hyprlock lock screen

platforms/hyprlock/jylhis-{paper,roast}.conf

Boot → login → desktop stays one look. The password field carries the same selected-item language as everywhere else — a 2px accent-family border on a surface fill, accent while verifying, status-err on a failed attempt. Colors and fonts only; auth and grace stay the consumer's.

Emacs · jylhis-paper / jylhis-roast

platforms/emacs/{jylhis-paper-theme,jylhis-roast-theme,jylhis-theme-toggle}.el

Modus-style semantic face targeting: same syntax colors as the terminal, same accent on line-number-current-line, vertico-current, org-level-1, magit branch-current. Toggle with M-x jylhis-toggle-theme.

Charm TUI · bubbletea + lipgloss + bubbles

platforms/charm/jylhis/{palette,theme,bubbles,bubbletea}.go · demo/

Go package exposing the full Jylhis palette as pre-built lipgloss.Styles. Auto-swaps paper ↔ roast from tea.BackgroundColorMsg. Ships themed list, help, spinner, textinput bubbles and a default keymap that mirrors the web shortcuts (/ filter, ^K palette, ^⇧L theme).
