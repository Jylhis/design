jylhis design system

Warm paper, earth copper. v0.1

A design system for jylhis.com — one accent, muted taupe everything else, monospace headings, serif body. Ten platform targets from Ghostty to Charm TUI, all driven by a single token spec.

WCAG AAA body Literata + JetBrains Mono Modus syntax keyboard-first no shadows

tokens.md Canonical palette spec — core colors, syntax, ANSI 16, typography, density, motion, sound, keyboard primitives.
