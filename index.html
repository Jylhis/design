paper

jylhis design system

Warm paper, earth copper. v0.1

A design system for jylhis.com — one accent, muted taupe everything else, monospace headings, serif body. Ten platform targets from Ghostty to Charm TUI, all driven by a single token spec.

WCAG AAA body Literata + JetBrains Mono Modus syntax keyboard-first no shadows

core palette

view full palette reference (rgb · hsl · oklch · contrast pairs) ▸

syntax · modus

ModusOperandi (light) and Vivendi (dark) syntax colors, imported verbatim from Protesilaos.

status · signal

Signalerr · warn · ok · info; reuses the Modus accents.

ansi 16 · spectrum

Spectrumslot 11 is intentionally overridden to brand copper.
